# Utaun คืออะไร?  
  
Utaun คือซอฟต์แวร์สำหรับ Windows ที่สร้างเสียงร้องแบบ CV (พยัญชนะ-สระ) สำหรับ UTAU โดยใช้การจำลองรูปคลื่นไซน์คอมโพสิตที่ไร้ชีวิตชีวา (การสังเคราะห์เสียงพูด CSM) เท่านั้น  
รองรับการสร้างไฟล์ ZIP ของแบงค์เสียงในโฟลเดอร์ Documents โดยอัตโนมัติ รวมถึงการส่งออกโดยตรงไปยังซอฟต์แวร์ที่รองรับ UTAU ต่างๆ  

# คุณสมบัติ  

* สร้างไฟล์ ZIP ของแบงค์เสียงในโฟลเดอร์ Documents ของคุณโดยอัตโนมัติ หรือส่งออกไปยังซอฟต์แวร์ที่รองรับโดยตรงเมื่อเปิดใช้งาน  
* สร้างเสียงสระ (A, I, U, E, O, N) ผ่านการจำลองรูปคลื่นไซน์คอมโพสิตที่ไร้ชีวิตชีวา (การสังเคราะห์เสียงพูด CSM)  
* ตั้งค่าโฟลเดอร์พยัญชนะและเสียงก้องที่รวมอยู่ในไดเรกทอรี Documents ของคุณเพื่อสร้างแบงค์เสียง CV  
* สร้างแถว m, n, y และ w ภายในโปรแกรมโดยอัตโนมัติ  
* รองรับนามแฝงฮิระงะนะ + นามแฝงโรมาจิภาษาอังกฤษ (การออกเสียงทั้งหมดเป็นภาษาญี่ปุ่น)  
* สร้าง `oto.ini`, `character.txt` และ `readme.txt` โดยอัตโนมัติ  
* แปลงภาพ PNG เป็นรูปแบบ JPG และ BMP พร้อมกัน (หมายเหตุ: ใช้ JPG สำหรับ `character.txt`)  
* การเข้ารหัสของ `readme.txt` และ `character.txt` สามารถเลือกได้ระหว่าง **Shift-JIS (ANSI)** และ **UTF-8** (หมายเหตุ: UTF-8 ช่วยให้มั่นใจว่าเข้ากันได้กับ OpenUTAU และอื่นๆ)  
* อนุญาตให้เปลี่ยนความถี่พื้นฐาน (ระดับเสียง)  
* ชื่อแบงค์เสียง (ชื่อตัวละคร) ที่ปรับแต่งได้อย่างอิสระ  
* **รองรับโหมดสว่างและโหมดมืด**  
* **อนุญาตให้เลือกปลายทางการส่งออกได้**  

# วัตถุประสงค์การใช้งาน  

* เมื่อคุณต้องการสร้างแบงค์เสียง UTAU โดยใช้เสียงที่ไร้ชีวิตชีวาหรือเสียงสังเคราะห์  
* สำหรับการผลิตแบงค์เสียงหากคุณรู้สึกว่าการบันทึกด้วยเสียงของคุณเองเป็นเรื่องยากหรือไม่สะดวก  
* การวิจัยวัสดุเสียงตามการจำลองรูปคลื่นไซน์คอมโพสิต (การสังเคราะห์เสียงพูด CSM)  
* การสร้างต้นแบบ (Prototyping) แบงค์เสียงที่กำหนดเอง  
* การแตกไฟล์ ZIP ที่สร้างขึ้นเพื่อใช้โดยตรงเป็นทรัพยากรโวคอลลอยด์จำลองเสียงมนุษย์  
* ใช้เป็นวัสดุเสียงสำหรับรีมิกซ์วิดีโอ (เช่น OtoMAD, YTPMV)  

# วิธีใช้ Utaun  

① ดาวน์โหลด Utaun เวอร์ชันล่าสุดจาก **[GitHub Releases](#Releases)**  
② หากคุณดาวน์โหลดเวอร์ชันโฟลเดอร์ ZIP **ให้วางโฟลเดอร์ "Consonant/Voiced Sound" และ `oto.ini` ลงในโฟลเดอร์ "Documents" ของคุณโดยตรง (รองรับ OneDrive Documents ด้วย)** (หมายเหตุ: จะถูกวางโดยอัตโนมัติหากใช้เวอร์ชันตัวติดตั้ง)  
③ วาง `Utaun.exe` ในโฟลเดอร์ใดก็ได้ที่คุณเลือก  
④ เริ่มต้นใช้งาน `Utaun.exe` และทำตามคำแนะนำบนหน้าจอเพื่อสร้างแบงค์เสียงของคุณ  
⑤ สำหรับตำแหน่งการบันทึกข้อมูล คุณสามารถเลือกระหว่างการส่งออกเป็น ZIP (Documents ฯลฯ) หรือส่งออกโฟลเดอร์โดยตรงไปยัง UTAU และ OpenUTAU  
*หมายเหตุ: คุณสมบัติการอัปเดตอัตโนมัติจะพร้อมใช้งานในเวอร์ชันอนาคต*

# ความเข้ากันได้และการใช้งานแบงค์เสียงที่สร้างขึ้น  

* **UTAU**  
  ส่งออกโดยตรงเป็นโฟลเดอร์แบงค์เสียงที่ไม่ได้บีบอัดไปยังโฟลเดอร์ `voice` ของคุณจากภายในแอปและใช้งานได้ทันที  
* **OpenUTAU**  
  ส่งออกโดยตรงเป็นโฟลเดอร์แบงค์เสียงที่ไม่ได้บีบอัดไปยังโฟลเดอร์ `Singers` ของคุณจากภายในแอปและใช้งานได้ทันที  
* **UtauTTS**  
  แตกไฟล์ ZIP ที่ส่งออกแล้ววางลงในโฟลเดอร์ `voice` ของ `utauTTS`  
* **UtauV**  
  ลากและวางไฟล์ ZIP ลงในหน้าต่างแอปพลิเคชัน UtaunV ที่กำลังทำงานอยู่  
* **UTAlet (เวอร์ชันเว็บ)**  
  ลากและวางไฟล์ ZIP ลงบนหน้าจอของเว็บไซต์อย่างเป็นทางการ  
*หมายเหตุ: สำหรับคำแนะนำการใช้งานเฉพาะในแต่ละซอฟต์แวร์หรือสภาพแวดล้อมเว็บ โปรดดูไฟล์ช่วยเหลือ คู่มือ หรือเอกสารอย่างเป็นทางการที่เกี่ยวข้อง*  

# ความต้องการของระบบ  

* Windows 10 ถึง 11 (รองรับ 64-bit / 32-bit)  
**(หมายเหตุ: เวอร์ชัน 32-bit ถูกใช้เป็นพื้นฐานเนื่องจากขนาดไฟล์ แต่โปรแกรมสามารถทำงานบน Windows 64-bit ได้อย่างราบรื่นเช่นกัน)**  

# คุณสมบัติที่ไม่รองรับ  

* สระที่มีเสียงก้อง (あ゙, い゙, ゔ, え゙, お゙)  
* รูปแบบการแสดงออกที่หลากหลาย เช่น เสียงกระซิบ เสียงลมหายใจ หรือส่วนประกอบของการเป่าลม  
* เสียงเพดานปาก (เช่น kya, kyu, kyo / sha, shu, sho)  
* VCV (สระต่อเนื่อง)  
* CVVC  
* การออกเสียงพิเศษอื่นๆ
