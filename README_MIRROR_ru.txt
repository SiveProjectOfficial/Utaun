# Что такое Utaun?  
  
Utaun — это программа для Windows, которая генерирует CV-войсбанки (согласная-гласная) для UTAU, используя исключительно неживое моделирование составных синусоид (синтез CSM).  
Она поддерживает автоматическое создание ZIP-архива войсбанка в папке «Документы», а также прямой экспорт в различные программы, совместимые с UTAU.  

# Особенности  

* При запускe автоматически создает ZIP-архив войсбанка в папке «Документы» либо экспортирует его напрямую в совместимое ПО.  
* Генерация гласных (A, I, U, E, O, N) с помощью исключительно неживого моделирования составных синусоид (синтез CSM).  
* Настройте прилагаемые папки согласных и звонких звуков в каталоге «Документы» для генерации CV-войсбанков.  
* Автоматическое создание рядов m, n, y и w прямо в программе.  
* Поддержка псевдонимов на хирагане + английских ромадзи-псевдонимов (произношение всех звуков — японское).  
* Автоматическое создание файлов `oto.ini`, `character.txt` и `readme.txt`.  
* Одновременное конвертирование PNG-изображений в форматы JPG и BMP (Примечание: для `character.txt` используется JPG).  
* Кодировку `readme.txt` и `character.txt` можно выбирать между **Shift-JIS (ANSI)** и **UTF-8** (Примечание: UTF-8 обеспечивает совместимость с OpenUTAU и другими программами).  
* Возможность изменения основной частоты (высоты голоса).  
* Свободно настраиваемое имя войсбанка (имя персонажа).  
* **Поддержка светлой и темной тем.**  
* **Возможность выбора места назначения экспорта.**  

# Предполагаемое использование  

* Когда вы хотите создать войсбанки UTAU, используя неживые или искусственные голоса.  
* Для создания войсбанков, если вам трудно или некомфортно записывать звук собственным голосом.  
* Исследование аудиоматериалов на основе моделирования составных синусоид (синтез CSM).  
* Прототипирование собственных войсбанков.  
* Распаковка созданного ZIP-архива для использования напрямую в качестве материалов для человеческого вокалоида.  
* Использование в качестве аудиоматериалов для видеоремиксов (например, ОтоМАД, YTPMV).  

# Как использовать Utaun  

① Скачайте последнюю версию Utaun на странице **Releases**.  
② Если вы скачиваете версию в виде ZIP-папки, **поместите папки «Согласные/Звонкие звуки» и файл `oto.ini` прямо в папку «Документы» (поддерживаются и Документы OneDrive).** (Примечание: при использовании установщика они размещаются автоматически).  
③ Поместите файл `Utaun.exe` в любую папку по вашему выбору.  
④ Запустите `Utaun.exe` и следуйте инструкциям на экране для создания войсбанка.  
⑤ В качестве места сохранения данных вы можете выбрать вывод в ZIP (Документы и т.д.) или прямой экспорт в виде папки для UTAU и OpenUTAU.  
*Примечание: Функция автоматического обновления будет доступна в будущих версиях.*

# Совместимость и использование созданных войсбанков  

* **UTAU**  
  Экспортируйте напрямую в виде распакованной папки войсбанка в папку `voice` из приложения и используйте сразу.  
* **OpenUTAU**  
  Экспортируйте напрямую в виде распакованной папки войсбанка в папку `Singers` из приложения и используйте сразу.  
* **UtauTTS**  
  Распакуйте экспортированный ZIP-файл и поместите его в папку `voice` программы `utauTTS`.  
* **UtauV**  
  Перетащите ZIP-файл мышкой (Drag & Drop) в окно запущенного приложения UtauV.  
* **UTAlet (Веб-версия)**  
  Перетащите ZIP-файл мышкой на экран официального веб-сайта.  
*Примечание: Инструкции по конкретному использованию в каждой программе или веб-среде см. в их соответствующих справочных файлах, руководствах или официальной документации.*  

# Системные требования  

* Windows 10 — 11 (поддерживается 64-бит / 32-бит)  
**(Примечание: 32-битная версия используется в качестве базовой из-за размера файлов, но программа также отлично работает на 64-битной Windows.)**  

# Неподдерживаемые функции  

* Озвученные гласные (あ゙, い゙, ゔ, え゙, お゙)  
* Выразительные вариации, такие как шепот, вздохи или придыхание  
* Смягченные звуки (например, kya, kyu, kyo / sha, shu, sho)  
* VCV (Непрерывные гласные)  
* CVVC  
* Прочие специальные произношения
