# Utaun란?  
  
Utaun은 완전 무생물의 가산 합성만으로 UTAU용 CV 음성 뱅크를 생성하는 Windows 소프트웨어입니다.  
문서 폴더로의 ZIP 자동 생성 및 각종 UTAU 관련 소프트웨어로의 직접 내보내기를 지원합니다.  

# 특징  

* 실행 시 문서 폴더에 음성 뱅크 ZIP을 자동 생성하거나 호환 소프트웨어로 직접 내보내기  
* 완전 무생물의 가산 합성을 통한 모음 생성 (A, I, U, E, O, N)  
* 동봉된 자음부 및 탁음부 폴더를 문서 디렉토리에 세팅하여 CV 음성 뱅크 생성  
* 프로그램 내에서 m, n, y, w 행을 자동 생성  
* 히라가나 별칭 + 영어 로마자 별칭 지원 (발음은 모두 일본어)  
* `oto.ini`, `character.txt`, `readme.txt` 자동 생성  
* PNG 이미지를 JPG 및 BMP로 동시 변환 (※ `character.txt`에는 JPG가 사용됩니다)  
* `readme.txt`와 `character.txt`의 인코딩을 **Shift-JIS (ANSI)**와 **UTF-8** 중에서 선택 가능 (※ UTF-8은 OpenUTAU 등과 호환됩니다)  
* 기본 주파수(음의 높이) 변경 가능  
* 음성 뱅크 이름(캐릭터 이름)을 자유롭게 설정 가능  
* **라이트 모드 및 다크 모드 지원**  
* **내보내기 대상 선택 가능**  

# 상정 용도  

* 무생물의 목소리로 UTAU 음성 뱅크를 만들고 싶을 때  
* 육성 녹음이 부담스럽거나 어려운 사람의 음성 뱅크 제작  
* 가산 합성 음성 소재 연구  
* 자작 음성 뱅크 프로토타이ピング  
* 생성된 ZIP을 압축 해제하여 인력 보카로 소재로 직접 사용  
* 매드무비(OtoMAD, YTPMV) 등의 소재로 활용  

# Utaun 사용법  

① **[GitHub Releases](#Releases)**에서 최신 버전의 Utaun을 다운로드합니다.  
② ZIP 폴더 버전을 다운로드하시는 경우, **"자음부/탁음부 폴더"와 `oto.ini`를 "문서" 폴더(OneDrive 문서도 가능) 안에 직접 넣어주세요.** (※ 설치 프로그램 버전을 이용하시는 경우 자동으로 배치됩니다)  
③ `Utaun.exe`를 원하는 폴더에 놓습니다.  
④ `Utaun.exe`를 실행하고 화면의 안내에 따라 음성 뱅크를 만듭니다.  
⑤ 데이터 저장 위치로 문서 폴더 내 ZIP 출력 외에도, UTAU 및 OpenUTAU로의 직접 폴더 내보내기를 선택할 수 있습니다.  
※ 향후 버전부터는 자동 업데이트 기능을 이용하실 수 있습니다.

# 생성된 음성 뱅크의 대응 및 사용법  

* **UTAU**  
  앱 내에서 `voice` 폴더로 음성 뱅크 폴더 상태 그대로 직접 내보내어 바로 사용할 수 있습니다.  
* **OpenUTAU**  
  앱 내에서 `Singers` 폴더로 음성 뱅크 폴더 상태 그대로 직접 내보내어 바로 사용할 수 있습니다.  
* **UtauTTS**  
  출력된 ZIP 파일을 압축 해제한 뒤, `utauTTS`의 `voice` 폴더에 넣고 사용합니다.  
* **UtauV**  
  ZIP 형식의 파일을 실행 중인 UtauV 앱 창에 드래그 앤 드롭(D&D)하여 사용합니다.  
* **UTAlet (웹 버전)**  
  ZIP 형식의 파일을 공식 웹사이트 화면에 드래그 앤 드롭(D&D)하여 사용합니다.  
※ 각 소프트웨어 및 웹 환경에서의 구체적인 이용 방법은 각 헬프, 매뉴얼, 공식 문서를 참조해주세요.
