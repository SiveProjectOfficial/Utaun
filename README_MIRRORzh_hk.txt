# 乜嘢係 Utaun？  
  
Utaun 係一套 Windows 軟件，純粹透過完全無生物嘅複合正弦波建模（CSM語音合成）嚟為 UTAU 生成 CV（輔音-元音）音源。  
佢支援喺「文件」資料夾入面自動生成音源 ZIP，以及直接匯出去各種相容 UTAU 嘅軟件。  

# 特點  

* 執行之後可以直接喺文件資料夾生成音源 ZIP，或者直接匯出至相容軟件。  
* 透過完全無生物嘅複合正弦波建模（CSM語音合成）生成元音（A、I、U、E、O、N）。  
* 將附帶嘅輔音同濁音資料夾放喺文件目錄入面，就可以生成 CV 音源。  
* 喺程式入面自動生成 m、n、y、w 行。  
* 支援平假名別名 + 英文羅馬字別名（發音全部都係日文）。  
* 自動生成 `oto.ini`、`character.txt` 同 `readme.txt`。  
* 同時將 PNG 影像轉換成 JPG 同 BMP 格式（註：`character.txt` 用嘅係 JPG）。  
* `readme.txt` 同 `character.txt` 嘅編碼可以喺 **Shift-JIS (ANSI)** 同 **UTF-8** 之中二選一（註：UTF-8 支援 OpenUTAU 等軟件）。  
* 可以更改基本頻率（音高）。  
* 可以隨意設定音源名稱（角色名）。  
* **支援淺色同深色模式。**  
* **支援選擇匯出目的地。**  

# 預期用途  

* 想用無生物或者人工聲音嚟整 UTAU 音源嗰陣。  
* 如果覺得用自己把聲錄音好難或者好尷尬，想用呢個嚟製作音源。  
* 研究複合正弦波建模（CSM語音合成）音頻素材。  
* 自製音源嘅原型製作。  
* 解壓生成嘅 ZIP，直接當係人手 Vocaloid 素材咁用。  
* 用嚟做影片混音（例如鬼畜音MAD、YTPMV 等）嘅音頻素材。  

# 點樣用 Utaun  

① 喺 **Releases** 下載最新版本嘅 Utaun。  
② 如果你下載嘅係 ZIP 資料夾版本，**請將「輔音/濁音資料夾」同 `oto.ini` 直接擺喺「文件」資料夾入面（亦都支援 OneDrive 文件）。**（註：如果用安裝程式版本嘅話會自動擺好）  
③ 將 `Utaun.exe` 擺喺你鍾意嘅任何資料夾入面。  
④ 啟動 `Utaun.exe`，然後跟住畫面嘅指示嚟建立音源。  
⑤ 喺資料儲存位置方面，除了 ZIP 輸出（文件等）之外，仲可以選擇直接以資料夾狀態匯出去 UTAU 同 OpenUTAU。  
*註：自動更新功能將會喺未來嘅版本提供。*

# 生成音源嘅支援與使用方法  

* **UTAU**  
  可以直接喺App入面以音源資料夾狀態匯出去 `voice` 資料夾度即刻使用。  
* **OpenUTAU**  
  可以直接喺App入面以音源資料夾狀態匯出去 `Singers` 資料夾度即刻使用。  
* **UtauTTS**  
  解壓匯出咗嘅 ZIP 檔案，然後將佢放入 `utauTTS` 嘅 `voice` 資料夾入面。  
* **UtauV**  
  將 ZIP 格式嘅檔案拖放去行緊嘅 UtauV 應用程式視窗度。  
* **UTAlet（網頁版）**  
  將 ZIP 格式嘅檔案拖放去官方網站介面度。  
*註：關於各個軟件或者網頁環境入面嘅具體使用方法，請參閱佢哋各自嘅說明檔案、手冊或者官方文件。*  

# 系統需求  

* Windows 10 到 11（支援 64位元 / 32位元）  
**(註：基於檔案大小等考量，以 32位元版本作為基準，但喺 64位元 Windows 上面都一樣正常運作。)**  

# 不支援嘅功能  

* 濁元音（濁音、帶濁音嘅元音類）  
* 耳語、呼吸聲、氣聲等表情差異  
* 拗音（kya、kyu、kyo / sha、shu、sho 等）  
* 連續音（VCV）  
* CVVC  
* 其他特殊發音  

# 使用條款  

關於 Utaun 本體（`Utaun.exe`），嚴禁以下行為：  
* 加工  
* 編輯  
* 改造  
* 商業用途  
* 再分發  
* 反編譯（拆解）  

# 關於生成嘅內容  

（音源、`.wav` 檔案、`icon.jpg` / `icon.bmp`、`oto.ini` 等）  
你（發布者）可以自由設定生成內容嘅使用條款。  
請喺 `readme.txt` 入面寫低你鍾意嘅使用許可條款。
